POST /api/xai/treinar

Objetivo: Treinar/atualizar o modelo de dureza.

Permissao: usuario autenticado com papel admin.

HTTP Significado
200Treino concluido com sucesso.
400Erro de regra de negocio (ex.: dados insuficientes).
403Usuario sem permissao.
503Servico de IA indisponivel.
500Erro inesperado.
